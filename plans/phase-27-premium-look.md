# Phase 27 — Premium look (optional)

> Order 4 in the [active queue](README.md). Do this only if time remains after creator, landing
> and catalog polish. Skip or cut it rather than compressing submission.

## Scope and boundaries

Optional, timeboxed pass over the shared graphic system so landing, catalog and creator chrome
read as one more premium product. This is token, type, surface and spacing work — not a new
visual language, not 3D product-model work and not new features.

Stay on the existing light slate/white surfaces, navy text, blue actions, green budget indicators
and amber warnings unless a small, coherent shift still fits the remaining time. Do not introduce
a new layout library or rewrite components for visual effect alone.

## Remaining outcome

- Shared surfaces look more refined and consistent across landing, catalog and creator chrome.
- Contrast, type hierarchy, control styling and empty/error states feel finished rather than
  prototype-rough.
- No regression in the creator flicker fixes, landing images/copy or catalog UI.

## Work sequence

1. Decide whether the remaining calendar still allows this pass. If not, cut it from the index
   and go to submission.
2. Apply a small coherent set of visual-system changes, then spot-check landing, catalog,
   creator and summary.
3. Stop when the look is clearly better, or when further tweaks would delay manual tests.

## Exit gate

Either the premium pass is in, or it was explicitly cut for time. Transfer durable visual-system
decisions into the relevant UI docs, then remove this plan and its index row.
